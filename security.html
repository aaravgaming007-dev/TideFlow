Verify via Terminal CLI

You can also verify checksums manually via your command line interface before installing:

Windows (PowerShell):
Get-FileHash .\TideFlow.apk -Algorithm SHA256
Linux / Android Termux:
sha256sum TideFlow.apk
macOS:
shasum -a 256 TideFlow.apk

Permissions Transparency

INTERNET

Required solely to fetch audio streams from YouTube Music and download lyric LRC files.

MEDIA PLAYBACK

Allows background audio playback when the screen is turned off or while switching applications.

NOTIFICATIONS

Displays lock screen media playback notification with skip, pause, and album artwork controls.

ZERO SNOOPING

No Location, no Contacts, no Camera, and no Microphone permissions are requested or used.
